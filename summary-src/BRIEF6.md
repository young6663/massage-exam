# 第六輪：補齊快速卡（只改 out/NN.json）

使用者是視障者，週五（2026-11-13）考按摩乙級術科，考場抽兩題。這張「快速卡」是她抽到題目後
用來看關鍵字回想內容的，看到關鍵字要能想起整段口述。**不是創造新內容**，所有字都必須出自原文。

- 原文：`summary-src/src/NN.txt`（每題一檔）。來源優先：「重點整理版（主要）」→ 規範版 → 講義版。
- 步驟原文：`summary-src/steps.json` 的 `NN.teacher`（沒有就用 `NN.spec`）。
- 你只能改分配給你的題號的 `summary-src/out/NN.json`。不可動 out3、index.html、summary.html、template.html、其他題號。
- 現有欄位的寫法規則見 `summary-src/BRIEF5.md`（先讀它）。

## 絕對不能動
- 所有 `mnemonic` 欄位的值（口訣一字不改）。若把某個含 mnemonic 的 extra_sections 搬到 overview，mnemonic 值必須原封不動。
- `num`、既有的 `src` 標記。
- 數字與專有名詞（年齡、比例、角度、天數、神經節段、肌肉／神經／韌帶／穴位名稱）不可寫錯，照原文。

## 要做的四件事

### 1. 新增 `overview`（概述：考生開頭向評審介紹這個病的說法）
每題都要有。格式：
```json
"overview": {"mnemonic": null, "items": ["椎間盤變性、纖維環破裂", "髓核後外突、壓神經根", "下腰痛、坐骨神經痛"], "src": "重"}
```
- 取自原文「重點整理版」的【概述】（沒有才用規範／講義的【概述】，src 填「規」或「講」）。
- items 最多 3 條、每條最多 12 個中文字，關鍵字用「、」分隔，不寫句子。要涵蓋：別名／俗稱（若有）、這是什麼病（機轉一句）、主要表現。
- 若 extra_sections 裡已有 label 含「概述」或「別名」的項目：把內容併進 overview（有 mnemonic 的照搬 mnemonic 與 items，不受 3 條限制），然後**從 extra_sections 刪掉那一項**，避免重複。

### 2. 新增 `steps_brief`（施術步驟關鍵字，一步一條）
格式：字串陣列，條數與 steps.json 的 teacher（沒有就 spec）步驟數相同、順序相同。
```json
"steps_brief": ["俯臥：擦揉壓腰兩側到跟腱（患側）", "腹前墊枕：壓9穴、掌壓督脈T11到尾骨", "側臥：旋腰運動", "仰臥：大腿前外、小腿外、足背", "掌根揉腿外側、直腿抬高運動", "壓6穴、搓揉下肢熱透"]
```
- 每條最多 16 個中文字。體位有變才在開頭寫「俯臥：」「仰臥：」「側臥：」「坐位：」。
- **一定要保留**：體位、墊枕（位置）、運動法名稱、測試／檢查名稱、擦熱／搓熱／熱透、只做患側／雙側、禁忌提醒（如「不可扳」）。
- 穴位不列名稱，只寫「壓N穴」（N 照原文該步驟的穴數；原文沒寫數字就自己數該步驟列的穴名）。
- 手法用原文的字（輕擦、揉捏、按壓、彈撥、搓、抖、拔伸…），不要換同義詞。
- 不要加步驟編號（頁面會自動編號）。

### 3. 補 `purpose`／`cautions`
- 若目前是 null，但原文有【施術目的】／【注意事項】：照 BRIEF5 格式補上（type：通用／通用+補充／專屬；extra 每條 12 字內、最多 3 條）。原文真的沒有就維持 null。
- 判斷 type：原文只寫通用口訣（放恢消促舒舒解解／保手休護鍛骨禁飲冰）＝「通用」；口訣外另有本題專屬內容＝「通用+補充」；完全不用通用口訣＝「專屬」。

### 4. 漏項檢查（對照重點整理版，只補不改寫）
逐段對照原文「重點整理版」的【病因病理】【臨床表現】【相關解剖】【施術目的】【注意事項】【檢查測試】，
現有 JSON 若漏掉下列「考試會被問、口述一定要講」的關鍵字就補上（照 BRIEF5 的關鍵字寫法）：
- 人：年齡、男女比、職業／族群
- 地：壓痛點／部位、神經節段
- 解剖：**肌肉名稱**（使用者特別要看肌肉）、神經、韌帶、骨性標誌。anatomy.items 可到 6 條，最重要的放前 3 條。
- 病理關鍵字、分型／分期名稱、禁忌（禁用的運動法或手法）
- 原文標明「考試一定要說」「重中之重」的內容
其他清單維持最多 4 條（確實需要可到 6 條，重要的放前 3 條）。**不要刪減現有內容、不要重寫已經正確的條目。**

## 交件
- 每檔改完用 Python `json.load` 驗證；寫入用 UTF-8、`ensure_ascii=False`、單行緊湊格式（與現狀相同）。
  Windows 上跑 Python 要加環境變數 `PYTHONIOENCODING=utf-8`。
- 改前先把所有 mnemonic 值收集起來，改後斷言集合相同（搬到 overview 的也算在內）。
- 最後回報（精簡，純文字）：每題一行「NN：overview 幾條、steps_brief 幾條、補了哪些漏項（列出新增的字）」；
  以及任何你不確定、原文互相矛盾、或找不到原文依據的地方。不要貼整份 JSON。
