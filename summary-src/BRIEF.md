# 按摩乙級術科 40 題比對索引表：逐題資料整理說明

## 背景
使用者週五（2026-11-13）要考按摩乙級術科，需要一張能快速複習的 40 題比對表。
每題的原始資料已抽成純文字：`src/NN.txt`（NN = 01–40），裡面分三個版本：
1. **重點整理版**（萬老師整理）：**主要來源**，口訣都在這裡
2. **規範版**：用來確認或補充（官方試題說明）
3. **講義版**：前兩者都沒有材料時，最後才用

你要把負責的每一題整理成一個 JSON 檔：`out/NN.json`（UTF-8，格式見下）。

## 最重要的規則
- **口訣一字不改**：直接從原文複製。不可自己編口訣、不可修正用字、不可把兩組合成一組。
  原文寫「病因口訣：勞姿反先骨。」→ mnemonic 填 `勞姿反先骨`（去掉句尾句號）。
- **不可用外部知識補內容**：所有項目都要找得到原文根據。原文沒寫神經節段，就不要自己寫 C5–C6。
- 項目（items）可以精簡改寫成短句（方便複習），但意思不可改，也不可增加原文沒有的內容。
- 口訣的逐項解釋（items）要**對齊口訣字序**：例如「晨反久勞天」五字對五項；每一項以口訣那個字開頭的方式呈現，例如 `晨：晨起或久坐痛，活動後減輕`。原文對不上字的，就照原文順序列出，在 note 說明。
- 有兩組口訣就列兩組（例如病因口訣＋病理口訣，或「或：…」的另一種寫法）。
- 每個欄位都要填 `src`：資料取自哪一版，用 `重`／`規`／`講`，可以多個，例如 `重+規`。
- 規範版和重點整理版有矛盾時，以重點整理版為主，在 `issues` 寫出差異。
- 某欄三個版本都沒有資料，就填 null，不要硬湊。

## JSON 格式
```json
{
  "num": "03",
  "etiology": [
    {"label": "病因口訣", "mnemonic": "勞姿反先骨",
     "items": ["勞：勞動或姿勢（長期彎腰負重）", "姿：…", "反：反覆腰傷", "先：先天因素", "骨：骨折"],
     "note": null, "src": "重"}
  ],
  "etiology_summary": null,
  "people": {"text": "長期彎腰工作的體力勞動者（如農夫）、腰肌力量薄弱者；中高年齡為多", "src": "重+規"},
  "timing": {"mnemonic": "晨反久勞天",
     "items": ["晨：晨起…", "反：反覆發作，時輕時重", "久：久坐…", "勞：勞累後加重，休息後減輕", "天：陰雨天加重，喜暖怕冷"],
     "note": null, "src": "重"},
  "location": {"text": "壓痛範圍廣泛", "src": "重"},
  "symptoms": {"mnemonic": null, "items": ["長期酸痛、脹痛，部分有下肢牽涉痛", "不靈活，但腰部活動無明顯障礙"], "src": "重"},
  "anatomy": {"mnemonic": null, "mnemonic_items": [],
     "items": ["肌肉：豎脊肌、腰方肌、髂腰肌、腹直肌、橫突間肌", "筋膜：胸腰筋膜", "韌帶：棘上、棘間韌帶"],
     "src": "重"},
  "purpose": {"type": "通用", "extra": null, "src": "重"},
  "cautions": {"type": "通用", "extra": null, "src": "重"},
  "extra_sections": [{"label": "測試檢查", "items": ["…"], "src": "重"}],
  "issues": ["…（版本間的差異、原文自相矛盾、建議向老師確認的地方）"]
}
```

### 各欄說明
- **etiology**：病因／病理口訣的陣列，每組一個物件。label 用原文的叫法（病因口訣、病理口訣…）。
  沒有任何口訣時填 `[]`，並在 **etiology_summary** 用 2–5 個短句寫出病因重點（`{"items":[...],"src":"…"}`）。
  有口訣時 etiology_summary 填 null。
- **people（人）**：好發族群的事實：男女比、年齡、職業、好發側等，**不放口訣**。
- **timing（事時）**：何時加重或減輕。原文有口訣就填 mnemonic 加對齊字序的 items；沒有口訣就 mnemonic 填 null，items 放重點。
- **location（地）**：壓痛點、疼痛位置。
- **symptoms（症狀）**：臨床表現裡人事時地以外的症狀。原文有症狀口訣就填 mnemonic 加對齊字序的 items；沒有就列 3–6 個重點短句。
- **anatomy（解剖）**：重點是**肌肉名稱、神經（第幾神經或神經根）、韌帶、骨骼**等考試會問的東西，每項一行，以「肌肉：」「神經：」「韌帶：」等開頭。
  原文有解剖口訣（例如「大下闊內小喙胸、小棘棘外大二三」）就填 mnemonic，mnemonic_items 寫每個字代表的結構。
- **purpose／cautions**（施術目的／注意事項）：
  - type 填 `通用`：使用全站通用口訣「放恢消促舒舒解解」／「保手休護鍛骨、禁飲冰」
  - type 填 `通用+補充`：通用口訣，再加本題專屬內容，寫在 extra（字串陣列）
  - type 填 `專屬`：完全不用通用口訣，extra 放本題內容重點（短句陣列）
  - 三個版本都沒有這一節：填 null
- **extra_sections**：本題特有、考試可能會問的段落（測試檢查、分類、診斷標準、頭痛種類…），精簡成短句。沒有就填 `[]`。
- **issues**：版本間的差異、原文錯字或矛盾、「考試不要說」之類的老師提醒。

## 交件
- 每題寫一個 `out/NN.json`，寫完用 `python -c "import json;json.load(open('out/NN.json',encoding='utf-8'))"` 驗證格式。
- 最後回報：完成哪些題、哪些題資料特別少或有疑問（每題一行）。不要回傳整份 JSON 內容。
